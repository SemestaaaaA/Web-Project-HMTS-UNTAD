## 1. Ringkasan Eksekutif & Objektif Sprint 1

Sprint 1 berfokus pada pembangunan **fondasi arsitektur perangkat lunak TALL Stack (Laravel Framework, Livewire 3, Alpine.js, Tailwind CSS)** dengan basis data MySQL tanpa ketergantungan Redis (*Zero-Redis Monolith*), serta merealisasikan **4 halaman portal publik terpisah** yang merefleksikan 100% prototipe paten pada [`preview.html`](../../preview.html).

### Poin Penyesuaian Khusus Pengguna pada Sprint 1:
1. **Headline Hero Monumental:** Diperbarui menjadi `HIMPUNAN MAHASISWA TEKNIK SIPIL` (menggantikan semboyan lama dan menghapus teks kecil di atasnya).
2. **Jargon Resmi Organisasi:** Menyematkan `#WeAreTheChampions` sebagai tagar resmi HMTS FT-UNTAD pada Hero Section, Quick Access Strip, Top Utility Bar, dan Footer.
3. **Penyajian Lambang Resmi:** Menempatkan lambang resmi besar HMTS FT-UNTAD (`docs/hmts.png` / `public/images/hmts.png`) di kolom kanan Hero Section secara mandiri dan bersih (**tanpa kotak pembungkus kartu dan tanpa teks di bawahnya**), didukung oleh pendaran cahaya ambien lembut (*diffused backlight glow*).
4. **Navbar Brand:** Ditampilkan resmi sebagai `HMTS FT-UNTAD` berdampingan dengan logo resmi.
5. **Konfigurasi Database Mandiri:** Skema migrasi, model, dan seeder telah disusun secara lengkap dan teruji secara fallback graceful sehingga siap dijalankan kapan saja oleh pengguna.

### 2.3 Skema Basis Data, Model & Seeder

1. **Tabel Database:**
   - `users`: Kolom `id`, `name`, `email`, `password`, `role` (`'superadmin'` / `'admin'`), `timestamps`.
   - `sessions`, `cache`, `jobs`: Tabel bawaan framework untuk menjalankan zero-Redis architecture di atas MySQL.
   - `periods`: Kolom `id`, `name` (`2026/2027`), `start_year`, `end_year`, `is_active`, `timestamps`.
   - `divisions`: Kolom `id`, `period_id`, `name`, `full_name`, `code`, `description`, `sort_order`, `timestamps`.
   - `members`: Kolom `id`, `period_id`, `division_id`, `name`, `nim`, `role_type` (`'ketua'`, `'bph'`, `'coordinator'`, `'staff'`), `position`, `batch`, `bio`, `sort_order`, `timestamps`.
2. **Model Eloquent:**
   - [`App\Models\User`](../../app/Models/User.php): Method otorisasi native `isSuperAdmin()` dan `isAdmin()`.
   - [`App\Models\Period`](../../app/Models/Period.php): Relasi `divisions()`, `members()`, dan method `Period::current()`.
   - [`App\Models\Division`](../../app/Models/Division.php): Scoped by `ActivePeriodScope`.
   - [`App\Models\Member`](../../app/Models/Member.php): Scoped by `ActivePeriodScope`.
   - [`App\Models\Scopes\ActivePeriodScope`](../../app/Models/Scopes/ActivePeriodScope.php): Penguncian data temporal multi-tenancy periode aktif berbasis database session/cache.
3. **Seeder Komprehensif ([`DatabaseSeeder.php`](../../database/seeders/DatabaseSeeder.php)):**
   - Akun Superadmin: `admin@hmts-untad.ac.id`
   - Akun Admin Harian: `pengurus@hmts-untad.ac.id`
   - Periode Aktif: `2026/2027`
   - Pimpinan Inti: Ketua & 4 BPH (Ketua 1, Ketua 2, Sekum, Bendum)
   - 8 Divisi Pelaksana Resmi: Ristek, Infokom, Penalaran, FKMTSI, Hublua, Bursa, Advokasi, Kaderisasi lengkap dengan koordinator awal.

## 4. Panduan Menjalankan untuk Pengembang / Pengguna

Saat Anda telah menyiapkan basis data lokal MySQL (misalnya `hmts_db` di Laragon / XAMPP):
1. Pastikan berkas `.env` sesuai dengan kredensial database Anda:
   ```env
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=hmts_db
   DB_USERNAME=root
   DB_PASSWORD=
   ```
2. Jalankan migrasi dan seeder awal:
   ```bash
   php artisan migrate --seed
   ```
3. Jalankan server lokal:
   ```bash
   php artisan serve
   ```
4. Akses melalui peramban:
   - Beranda: `http://localhost:8000/`
   - Tentang Kami: `http://localhost:8000/tentang`
   - Kegiatan: `http://localhost:8000/kegiatan`
   - Layanan: `http://localhost:8000/layanan`
